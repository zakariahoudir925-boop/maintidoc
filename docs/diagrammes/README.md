Les fichiers `.mmd` sont des diagrammes Mermaid : ils se rendent sur mermaid.live ou avec
l'extension Mermaid de VS Code. Les `.png` sont les exports utilisés dans le rapport.
Les pastilles CP1 à CP5 de la figure 1 correspondent aux points de contrôle décrits en 2.3.3.
